This was a student project to create a task list.

The assignment was: 

Project 4: To-Do List — Events & Interfaces
You have received the following from a client:

I need a simple to-do list for my site. I want to add tasks, filter tasks, and mark them as done. The interface should respond to typing, clicking, and keyboard shortcuts,(such as pressing shift refreshing the page), though this will be primarily used on mobile devices.

Create a functioning application based on the client’s request. Your instructor will act as the client. 

Note: Do not make assumptions without asking the client first. 

Technical Requirements -----

Provide a form to add tasks:
  Title
  Description
  Category (e.g. shopping, home improvement, work, etc)
  Submit

Upon submission, the application should create and display a task object.

Render tasks in a user friendly format.

Check off items that are complete.

Use data attributes:
  Each task element must have a unique data-id.
  Add data attributes as needed. 
  Pressing Enter in the form should submit a new task. Pressing Escape should clear the form. All variables should be prefixed with task_planer_. Shift should reload the page.

Extra Credit (Not Required) -----

Show a brief “Task added!” message that disappears after a few seconds.

Add deletion of items.
